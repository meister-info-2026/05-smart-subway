Big Picture

우리는 무엇을 만들고 있나요?

지하철 중앙 관제 센터와 현장 객차 관리자의 친절한 대화입니다.

중앙 두뇌 (팀원 B 담당)
지하철 관제 센터 (백엔드+DB)
• 카메라가 세어준 사람 수로 혼잡도(여유/보통/혼잡)를 계산합니다.
• 웹 대시보드 명령을 받아 "LED를 무슨 색으로 켤지" 지시판에 적어둡니다.
• 라즈베리파이가 결과를 보고하면 대시보드에 즉시 띄워줍니다.
현장 실행자 (내 역할!)
객차 현장 관리자 (라즈베리파이 5)
• 1초마다 관제 센터 지시판을 보러 갑니다: "지금 무슨 불 켤까요?"
• 지시를 확인하면 화면에 [초록불 🟢 켜짐!] 글자를 찍습니다.
• 관제탑에 무전을 칩니다: "지시대로 초록불 켰습니다!"
The Contract

둘만의 비밀 통신 약속 3가지

이 3가지만 맞추면 백엔드 내부 코드를 몰라도 100% 통신됩니다.

① 친구네 집 주소
BACKEND_URL
백엔드가 켜진 PC의 IP 주소입니다.
http://192.168.0.25:8000
⚠️ localhost는 내 자신을 뜻하므로 안 돼요!
② 비밀 출입증
DEVICE_API_KEY
외부 침입자를 막는 우리 팀만의 암호입니다.
SUBWAY_2026_09_05_v1_0_0
글자 하나라도 틀리면 401 오류가 나요!
③ 장치 이름표
Device ID 목록
백엔드가 알고 있는 3가지 이름표입니다:
• led_congestion (혼잡도 안내등)
• motor_conveyor (배경 컨베이어)
• sensor_seat_pressure (임산부석)
Step 1: Polling (GET)

1초마다 관제탑 지시판 열어보기

"국장님! 지금 LED 무슨 색 켜야 하나요?" 라고 백엔드에 묻는 과정입니다.

📬 우체통 열어보기 (GET 요청)
라즈베리파이는 공인 IP가 없어서 백엔드가 먼저 찾아올 수 없습니다. 그래서 라즈베리파이가 1초마다 백엔드 우체통을 열어봅니다.
# 라즈베리파이가 보내는 주소
GET /api/v1/devices/led_congestion/desired-state
📋 백엔드가 건네주는 쪽지 (JSON 응답)
백엔드는 현재 목표 상태가 적힌 쪽지를 건네줍니다.
{
  "desired_state": "on",
  "desired_value": {
    "color": "GREEN", // 초록불!
    "level": "여유"
  }
}
Step 2: Report (POST)

"명령 수행 완료!" 무전 치기

실제로 장치를 반영한 뒤 관제탑에 결과를 보고해야 대시보드가 안심합니다.

📡 무전 보고하기 (POST 요청)
명령대로 LED를 켰다면, 백엔드에 "초록불 켰습니다!" 하고 보고서를 전송합니다. 이때 출입증(API 키) 도장을 찍어야 합니다.
# 헤더에 비밀 출입증 첨부 필수!
X-Device-Api-Key: SUBWAY_2026_09_05_v1_0_0

POST /api/v1/devices/led_congestion/state
✨ 무전이 도착하면 일어나는 일
백엔드가 보고서를 확인하고 웹 대시보드 화면에 즉시 결과를 띄웁니다.
웹 대시보드에 실시간 반영!
대시보드의 지하철 객차 혼잡도 LED가 초록색으로 빛나며 "정상 제어됨" 상태로 바뀝니다.
Safe Practice

전선 0개! 화면에 글자(print)로 흉내내기

통신도 안 되는데 전선부터 꽂으면 멘붕이 옵니다. 화면 글자로 100% 검증하세요!

❌ 초보자가 가장 많이 하는 실수
• 사자마자 빵판(브레드보드)에 전선 10개씩 꽂기
• 3.3V와 GND 합선(쇼트)으로 라즈베리파이 태워먹기
• 에러가 났을 때 전선 문제인지 통신 문제인지 알 수 없음
하드웨어 배선은 무조건 나중에!
통신이 정상 작동하는 걸 눈으로 먼저 확인한 뒤 배선해야 5분 만에 끝납니다.
✅ ELI5 권장: Print문으로 흉내내기
진짜 LED를 켜는 대신 모니터 화면에 예쁜 글자를 찍습니다.
# 실제 하드웨어 제어 대신 print문으로 출력!
if color == "GREEN":
  print("👉 [LED 흉내] 🟢 초록불 켜짐! (객차 여유)")
elif color == "RED":
  print("👉 [LED 흉내] 🔴 빨간불 켜짐! (객차 혼잡)")
